# 成片与人工复审

## 1. 层级、主次和遮挡

所有媒体进入 `public/`，使用 `staticFile()` 引用。动画只由 `useCurrentFrame()`、`interpolate()`、`spring()`、SVG/Canvas 或可控遮罩驱动，不使用 CSS transition/animation。

Remotion 母版的层级是起点，不是构图的答案：

`stage → rear → subjectBack → occluder → subjectFront → graphic → keyword → chapter → transition → titleCard → caption`

每拍只有一个主焦点。辅助元素通过更小的尺寸、更低的对比、更少的细节或更远的位置让位。如果所有元素同样显眼，问题是规模、对比、间距和留白，不是 `z-index` 不够高。

遮挡只允许表达真实的空间关系或动作：人站在柜台后、手握住道具、前景擦过镜头完成转场。不允许为了填空而盖住其他元素。

下列区域始终保护：

- 脸和视线；
- 主动手势和道具接触点；
- 因果链的结果面板；
- 字幕区及人物脚部站位；
- 观众当前必须核对的数字和文字。

层级只表达前后关系，不能修补错误摆放。

## 2. 第一遍：接触页扫描

画面复审以真正打开接触页、高清帧和成片为准。不要为了显得严格而增加大量单元测试、截图计分或规则命中统计；这些数字不能判断人物是否残缺、遮挡是否合理或主次是否清楚。

渲染后优先直接传入含 `internal_events` 的 `collage-plan.json`：

~~~bash
python3 scripts/extract_visual_review_frames.py out/final.mp4 \
  --beats collage-plan.json --output review/final
~~~

必须打开并检查每一页：

- `full-1fps/`：扫全片节奏、构图复用、裁切、残片和内容退化；
- `ending-2fps/`：查最后一段是否突然只剩文字、流程和标题卡；
- `beat-start-mid-end/`：查每拍进入、中段、退出；如果计划含 `internal_events`，同页还会增加动作发生帧；
- `manifest.json`：把每格映射回具体时间、帧、动作事件和旁白。

接触页只负责快速定位。320×180 小格不能用来判断手指、发丝、透明边缘和一两像素的裁切。

## 3. 第二遍：可疑时间的高清单帧

从接触页和 `manifest.json` 记下可疑时间，重新运行：

~~~bash
python3 scripts/extract_visual_review_frames.py out/final.mp4 \
  --beats collage-plan.json --output review/final \
  --detail-times 6.233 237.933 254.633
~~~

`detail-frames/` 保存原分辨率 PNG。逐张查：

- 人物手脚、道具轮廓和群像边界是否完整；
- 全身人物和群像是否因为坐标加尺寸超过画布；如果确实越界，计划中是否有明确 `crop_intent`；
- 是否有棋盘格、白边、相邻格残片或透明毛边；
- 遮挡是否符合人物、柜台、道具和前景的真实前后关系；
- 主焦点是否一眼可见，辅助元素是否在抢注意力；
- 面板是否压脸、压手或盖住结果。

## 4. 第三遍：连续播放

从头到尾连续播放成片。重点看：

- 旁白换意时，主体、关系、动作或结果是否同步换；
- 遮挡是否在正确时间建立和解除；
- 短动画是否发生得太快，使抽帧页看不出穿模或跳变；
- 旁白停顿时的画面停留是否仍有明确信息；
- 最后 30 秒是否仍保持人物、道具和可见结果。

## 5. 根据现象找原因

| 现象 | 优先排查 |
|---|---|
| 组件在所有画面里都缺一块 | 源 PNG、图集切片、alpha 和边界 |
| 只在某个构图中被切 | 容器尺寸、`overflow`、`object-fit`、负坐标 |
| 完整人物或群像贴边缺头缺手 | 元素坐标加尺寸是否超出画布，是否缺少 `crop_intent` |
| 只在进入、移动或退出时被切 | 位移路径、缩放中心、动画容器和遮罩 |
| 只在转场时瞬间穿模 | 转场时机、前景遮挡层和两拍重叠 |
| 人物、道具、标题都在抢视线 | 主焦点尺寸、对比、间距、留白和细节密度 |
| 面板压住脸、手或结果 | 布局错误和保护区，不是简单调高层级 |

修复后至少重新渲染受影响的区间，重做对应接触页和高清单帧。母版、主角或共享布局改动后，重新看全片。

## 6. 交付前问题

- 关掉字幕后，能否大致理解谁对什么做了什么？
- 每拍是否只有一个主焦点？
- 所有遮挡是否都能说清真实的前后或接触关系？
- 所有全身人物和群像是否完整留在画布内？越界是否有明确而合理的 `crop_intent`？
- 是否有完整图片被切成半截、相邻格残片或越界？
- 是否存在一张图撑完整章，仅靠标签或轻微推拉维持？
