# 完整工作流

| 阶段 | 输入 | 方法 | 产出 |
|---|---|---|---|
| 任务建立 | 观众、目标、参考范围、画幅 | 明确缺失信息和任务边界 | 仓库外任务目录 |
| 参考研究 | 授权视频或本地媒体 | 连续观看、逐段记录、提炼方法 | 方法摘要与证据页 |
| 内容锁定 | 文案或研究材料 | 确认旁白文本，不在制作中随意改字 | 文案、旁白、字幕时间 |
| 视觉计划 | 旁白短句 | 拆语义动作、舞台、起点、动作、结果 | `collage-plan.json` |
| 资产准备 | 视觉计划 | 复用组件、代码绘制、ImageGen 补图 | 完整资产目录 |
| 引擎实现 | 计划、声音、资产 | Remotion 或 HyperFrames 实现 | 可渲染工程 |
| 成片复审 | MP4 | 连续观看和按需抽帧 | 修复后的最终 MP4 |

真实参考媒体、Cookies、文案、声音和输出保存在仓库外。长片、新画风或复杂合成可以先做代表内容；是否需要由项目风险决定。

工程完成后运行引擎自身检查并渲染 MP4，再用 `extract_visual_review_frames.py` 定位具体问题。只交付最终成片和必要说明，清理失败渲染、临时文件与进程。
